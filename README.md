# Template Frontend

Template HTML puro para proyectos de ramo frontend sin CSS ni JavaScript.

## Estructura

Este template proporciona una estructura HTML semántica y básica que incluye:

- **Header**: Navegación principal
- **Main**: Contenido principal con múltiples secciones
- **Sections**: 
  - Inicio
  - Acerca de
  - Servicios
  - Contacto con formulario
- **Footer**: Pie de página

## Características

- HTML5 semántico
- Sin dependencias externas
- Sin CSS ni JavaScript
- Totalmente personalizable
- Accesible y responsive-ready

## Cómo usar

1. Clona o descarga este repositorio
2. Abre `index.html` en tu navegador
3. Personaliza el contenido según tus necesidades
4. Añade CSS y JavaScript cuando sea necesario

## Estructura de archivos

```
template_frontend/
├── index.html
└── README.md
```

## Notas

- Recuerda cambiar el título de la página y el contenido
- Los enlaces en la navegación usan anchors (#) para navegar entre secciones
- El formulario de contacto es estructura HTML pura sin procesamiento backend
